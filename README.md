## 📁 주요 파일 및 문서 안내

1. **🌐 배터리 엔지니어 멀티 페이지 포트폴리오 홈페이지**: [index.html](file:///Users/chagyeongho/Desktop/test_folder/포트폴리오/index.html)
   - **3단계 화면 전환 시스템 (Stepped Multi-Page)**:
     - **1페이지 (기본 정보 & 스펙)**: 인적사항, 건국대 소속변경 스토리 배지, 어학(TOEIC/OPIc), 자격증(화공기사/위험물/화학분석 등), 3대 전공 역량, 배터리 분석 장비 스택

     - **3페이지 (배터리 실전 프로젝트)**: CR2032 코인셀 제작/평가, 슬러리 코팅 공정 개선, Python dQ/dV 분석 툴 및 연락처
   - **편의 기능**:
     - 상단 스텝 탭 및 하단 플로팅 네비게이터 (`[◀ 이전]`, `[다음 ▶]`, 키보드 좌우 방향키 지원)
     - `✏️ 실시간 편집 모드`: 브라우저에서 모든 텍스트를 클릭해 수정하고 `localStorage`에 자동 영구 저장
     - `📷 1초 사진 변경`: 프로필 사진 클릭 시 내 PC의 사진으로 즉시 교체
     - `📄 PDF / 인쇄`: 인쇄 시 1~3페이지 전체가 순서대로 깔끔한 A4 규격 문서로 출력

2. **📄 스펙 & 자기소개서 마스터 가이드**: [portfolio.md](file:///Users/chagyeongho/Desktop/test_folder/포트폴리오/portfolio.md)

## 🚀 빠른 시작 가이드 (이용법)

1. [index.html](file:///Users/chagyeongho/Desktop/test_folder/포트폴리오/index.html) 파일을 웹 브라우저(Chrome, Safari 등)로 엽니다.
2. 상단 탭 또는 하단 `[다음 페이지 ▶]` 버튼을 눌러 **1장(기본정보) ➜ 2장(자기소개서) ➜ 3장(프로젝트)** 순으로 살펴봅니다.
3. 우측 상단의 **`✏️ 실시간 편집 모드`**를 켜고 본인의 실제 점수, 세부 경험 내용을 직접 수정합니다.
4. 프로필 사진을 클릭하여 본인의 증명사진이나 프로필 사진을 등록합니다.
5. 입사 지원 시 **`📄 PDF / 인쇄`**를 눌러 PDF로 저장하거나 바로 인쇄합니다.
